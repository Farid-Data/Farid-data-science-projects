# Deep Learning Lab

A collection of hands-on deep learning projects focused on **Computer Vision, Convolutional Neural Networks (CNNs), and image classification**.

This repository is part of my practical journey through Deep Learning. The main goal is to understand the concepts behind neural networks by implementing them on real datasets, experimenting with different architectures, and evaluating their performance.

## Projects

### 1. MNIST — Handwritten Digit Classification

**Dataset:** MNIST
**Task:** Classify handwritten digits from 0 to 9.

Topics practiced:

* Neural network fundamentals
* Image preprocessing
* Convolutional Neural Networks
* Convolution and feature extraction
* Pooling
* Batch Normalization
* Dropout
* Model evaluation
* Confusion matrix
* Classification metrics

### 2. Fashion-MNIST — Clothing Image Classification

**Dataset:** Fashion-MNIST
**Task:** Classify grayscale images of clothing into 10 different categories.

Topics practiced:

* CNN architecture design
* Data augmentation
* Convolutional feature extraction
* Batch Normalization
* Pooling
* Dropout
* Global Average Pooling
* Flattening
* Model evaluation
* Confusion matrices and classification reports

### 3. CIFAR-10 — RGB Image Classification

**Dataset:** CIFAR-10
**Task:** Classify 32×32 RGB images into 10 object categories.

Topics practiced:

* Deeper CNN architectures
* RGB image processing
* Data augmentation
* Batch Normalization
* Pooling
* Dropout
* Feature maps
* Global Average Pooling
* Multiclass classification
* Model evaluation and error analysis

## Purpose

This repository is primarily a **learning and experimentation laboratory**.

Rather than focusing on production software engineering, the projects focus on understanding the theory and practical behavior of deep learning models, including:

**Data → Preprocessing → Augmentation → CNN → Feature Extraction → Classification → Evaluation**

As the projects become more advanced, I will experiment with different architectures, regularization techniques, optimization strategies, and computer vision approaches.

## Learning Progression

The projects are organized roughly from simpler to more challenging computer vision problems:

**MNIST → Fashion-MNIST → CIFAR-10**

This progression allows me to gradually move from basic image classification toward more complex computer vision tasks.
