## 🎯 Purpose

These notebooks serve several purposes:

1. **Learning** — understanding Deep Learning concepts from first principles.
2. **Experimentation** — testing different architectures, hyperparameters, and techniques.
3. **Documentation** — keeping track of important ideas and observations.
4. **Comparison** — comparing different approaches on the same or similar problems.
5. **Reference** — creating a personal knowledge base for future AI projects and interviews.

---

## 🔬 Learning Philosophy

The focus of these notebooks is not simply on making a model achieve a high accuracy.

For each important technique, I aim to understand:

* **Why does it exist?**
* **What problem does it solve?**
* **How does it work?**
* **What happens inside the model?**
* **When should it be used?**
* **What are its limitations?**
* **How does it compare with alternative approaches?**

The notebooks therefore combine theory, mathematics, implementation, experiments, and analysis whenever appropriate.
