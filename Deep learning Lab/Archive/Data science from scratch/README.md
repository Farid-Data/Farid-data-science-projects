# 📊 Data Science from Scratch

This folder contains my **Jupyter notebooks, exercises, implementations, and notes** while studying *Data Science from Scratch*.

## 📚 Contents

The notebooks cover practical implementations of fundamental Data Science concepts, including:

* 🐍 Python for Data Science
* 📐 Mathematics and Statistics
* 📊 Data Analysis
* 🤖 Machine Learning
* 📈 Data Visualization
* 🔢 Linear Algebra
* 📉 Probability and Statistics
* 🧠 Machine Learning Algorithms
* 🛠️ Practical Data Science techniques

## 🎯 Purpose

The goal of this collection is to **understand the underlying concepts by implementing them from scratch**, rather than relying only on high-level libraries.

Whenever appropriate, concepts are implemented manually first and then compared with established Python libraries such as:

* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## 🧪 Approach

Each notebook focuses on understanding **why and how** a method works.

The general workflow is:

```text
Concept
   ↓
Mathematical foundation
   ↓
Implementation from scratch
   ↓
Experimentation
   ↓
Library implementation
   ↓
Comparison
   ↓
Analysis
```
