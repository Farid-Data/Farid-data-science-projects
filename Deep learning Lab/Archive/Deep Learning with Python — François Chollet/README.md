# 🧠 Deep Learning with Python

This folder contains my **Jupyter notebooks, implementations, experiments, and notes** while studying *Deep Learning with Python* by **François Chollet**.

The purpose of this collection is to build a strong practical and theoretical foundation in Deep Learning through hands-on implementation with **Python and Keras**.

## 📚 Topics

The notebooks cover concepts such as:

* Neural Networks
* TensorFlow & Keras
* Tensors and Operations
* Data Preprocessing
* Binary Classification
* Multiclass Classification
* Regression
* Overfitting & Regularization
* Dropout
* Batch Normalization
* Convolutional Neural Networks (CNNs)
* Computer Vision
* Data Augmentation
* Sequence Models
* RNNs
* LSTMs
* GRUs
* NLP
* Attention Mechanisms
* Transformers
* Generative Deep Learning

## 🧪 Learning Approach
